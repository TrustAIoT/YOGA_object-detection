# Contributing to YOGA

Bug reports, questions and pull requests are welcome.

* **Issues:** open one at https://github.com/TrustAIoT/YOGA_object-detection/issues. Include your PyTorch and Python versions and the full command you ran.
* **Pull requests:** keep each one focused on one change, and check that `python detect.py` and `python val.py` still run.

The training and evaluation code comes from [YOLOv5](https://github.com/ultralytics/yolov5). For bugs in that shared code, the YOLOv5 issue tracker often already has the fix.
